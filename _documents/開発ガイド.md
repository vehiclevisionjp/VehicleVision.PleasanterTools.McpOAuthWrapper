# 開発者向けガイド

本書はソースコードを変更・検証する開発者向けです。製品の目的と利用状況は [README](../README.md) を参照してください。

## 開発環境を用意する

言語は C#、ランタイムは .NET 10 です。.NET 10 SDK と Git を用意します。通常のビルドでは Pleasanter 本体の取得は不要です。

```powershell
git clone https://github.com/vehiclevisionjp/VehicleVision.PleasanterTools.McpOAuthWrapper.git
cd VehicleVision.PleasanterTools.McpOAuthWrapper
dotnet restore --locked-mode
dotnet build --no-restore -c Release
dotnet test --no-build -c Release
dotnet run --project src/VehicleVision.PleasanterTools.McpOAuthWrapper --launch-profile http
```

`http://localhost:5154/health/live` は起動確認用です。General.json の Enabled が false の初期設定では `/mcp` は HTTP 501 を返します。認証と中継を使う際は [導入手順](導入手順.md) に従って設定してください。ローカル開発で HTTP を使う場合は Development と General.json の AllowDevelopmentHttp=true が必要です。HTTP を許可する接続先はループバックのみです。

## テスト

現在の HTTP テストは57件です。

- `/health/live` が HTTP 200 を返す。
- `/mcp` の GET／POST／DELETE が HTTP 501 を返し、受け取った API キーを応答に含めない（3件）。
- OAuth のログイン・同意・コード交換、PKCE、認可コードと同意チケットの再利用拒否、CSRF。
- データベースからの API キーの都度取得、変更・削除、無効化・ロックアウト・利用期限、個人／共通キー。
- SQL 注入、許可外の redirect URI と Origin、URL 内トークン、主体をまたぐ MCP セッションの拒否。
- トークンの更新・失効、接続元ごとの試行回数制限、SSE の逐次転送。

WebApplicationFactory、SQLite の Users フィクスチャ、HTTP 上流スタブを使います。Docker 上の Pleasanter 1.5.8.1／PostgreSQL 17 でも OAuth と MCP 接続を確認しました。SQL Server 2025・PostgreSQL 17・MySQL 8.4 の実ドライバーによる接続・Users の SELECT も Docker で確認済みです。Claude の組織コネクタと SQL Server・MySQL に接続した Pleasanter を通した OAuth/MCP 試験は未実施です。`dotnet test -c Release --collect "XPlat Code Coverage"` でカバレッジを採取できます。

## 参照ソースを取得する

## 開発運用と設計

画面は ASP.NET Core MVC と Razor Views でサーバー側レンダリングします。CSRF と HTML エスケープは標準機能を使います。現時点で JavaScript／CSS フレームワークと npm 依存はありません。

開発は `develop`、リリース確定状態は `master` とします。変更は Issue → `develop` から作業ブランチ → Draft PR の流れで進めます。

- [開発運用](開発運用.md)：Codex／Claude、Actions、GitHub App の設定、ブランチ運用
- [アーキテクチャ方針](アーキテクチャ方針.md)：実ソースの調査結果、認証・中継の実装方針と未決定事項

README は利用者向けの取扱説明・製品説明の入口とし、ビルド、テスト、開発ツール、CI、エージェント運用は本書と開発運用へ記載します。導入・接続・サインインなど、製品を使うための手順は利用者向け資料として記載します。

外部メモリリポジトリは現時点では作成していません。必要になった場合は `VehicleVision.PleasanterTools.McpOAuthWrapper.ClaudeMemory` を **Internal** で作成し、公開リポジトリに組織情報や秘密を持ち込まない構成にします。

## 依存更新の確認

2026-10-06 に NuGet の安定版を確認し、coverlet.collector 10.1.0、Microsoft.NET.Test.Sdk 18.10.1、xunit.runner.visualstudio 4.0.0 への Bot PR を develop に取り込みました。ランタイム依存も確認し、Yarp.ReverseProxy は解決済みの 2.3.0 に固定しました。推移的依存を含む NuGet 脆弱性検査で該当はありませんでした。

GitHub の公式リリースを確認した結果、checkout v7、setup-dotnet v6、upload-artifact v7、dependency-review-action v5、create-github-app-token v3、codeql-action v4 は現行メジャー版です。これらのメジャータグで修正版を追従します。npm の管理対象はありません。参照専用 Pleasanter の npm 依存は変更しません。

SDK も [公式リリースメタデータ](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json) を確認し、global.json を .NET 10 最新安定版の 10.0.401 へ更新しました（ランタイム 10.0.12）。ローカルの Release ビルド・テストは同 SDK で実行しています。


7言語の画面・エラー・同意は標準の Localization と resx を使います。実機試験とスクリーンショットの採取条件は [Docker 検証記録](https://github.com/vehiclevisionjp/VehicleVision.PleasanterTools.McpOAuthWrapper/blob/develop/_development/検証記録.md) にまとめています。
